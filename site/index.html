02 / GET STARTED

选择你的安装方式

已有游戏请原位升级，保留账号与游戏数据。

  1. 1

    准备好工具与 MuMu

    安装 Python 3.10 或更新版本与 Android Platform Tools。启动 64 位 MuMu，开启 ADB 调试。下载上方工具 ZIP，并完整解压，不要只单独下载 install_tw.py。

  2. 2

    运行一键向导

    在解压后的文件夹里双击 install_tw.py，或打开终端运行：

    py -3 install_tw.py

    选择“下载已校验最新版”，或者选择已下载的 {{VERSION}} XAPK。向导有中文提示；下载代理留空即直连。

  3. 3

    确认设备，再原位升级

    多个模拟器同时运行时，按向导编号选中目标。确认摘要后输入 y。工具会验证完整包及三个 split，以 -r 保留数据，并在升级前备份旧 APK。

    不会修改 Google 账号地区，也不会改动系统代理、VPN 或 DNS。

  4. 4

    看到 verified，再手动打开游戏

    安装器核对版本 {{VERSION}}（{{CODE}}）、全部 split 与安装来源。完成后游戏保持停止，由你手动启动；后续游戏内资源下载是正常的独立步骤。

    Android 手机使用 split 安装器

    Android 11+ 可用无线调试与 Shizuku；一次选择三个 APK，保持签名校验。升级使用原位安装，不先卸载或清除资料。

    安装完成后手动启动

    该流程绕开 Google Play 商店跳转，仅负责下载与安装。游戏登录和服务状态在启动后单独确认。

03 / HELP

遇到问题，先看这里

没有台区或日区 Google 账号，也能下载安装吗？

公开下载与原版 split 安装不要求 Google Play 账号改区。TW 与 JP 都从 GitHub Release 直接获取完整 XAPK；游戏登录和服务状态在启动后单独判断。

游戏提示“应用程序已推出新版本”

这是 Android 客户端升级提示。下载 {{VERSION}}（{{CODE}}）XAPK 后原位升级，不要重新安装旧版 1.1.2，也不需要先清除游戏资源。

以前教程的 GitHub 链接为什么显示 404？

仓库曾被设为私有；现在仓库、教程与发布下载已公开。请使用本页按钮获取最新文件。若浏览器仍显示旧内容，请刷新页面；历史 1.1.2 文件并不会自动更新。

安装失败、签名冲突或 split 缺失

请使用完整的同版本 XAPK，一次安装全部三个 APK。若显示 INSTALL_FAILED_UPDATE_INCOMPATIBLE，现有客户端可能签名不同；先保留资料并检查来源。不要关闭签名校验或卸载来试错。

向导找不到设备，或有多个模拟器

开启 MuMu ADB 调试。没有自动发现时输入该实例设置中显示的 ADB 地址；多个实例要明确选择。也可用 TW_ADB 指定 adb.exe 的路径。不要把教程示例端口直接当成你的设备端口。

安装成功之后，仍有网络或登录问题

安装、网络与账号登录需要分别判断。保留错误文字与版本信息，不要反复卸载或清数据。本工具不改变 VPN、代理、DNS 或游戏账号，也不收集密码、引继码或会话资料。
